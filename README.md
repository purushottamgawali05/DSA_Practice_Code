# Java Language and DSA Practice

This repository contains my Java learning notes, examples, and practice problems. It follows a topic-by-topic path from Java fundamentals to common data structures and algorithms.

## Topics Covered

- `Varibles_Datatypes` - variables and data types
- `Operators`, `Conditions`, and `Loops` - Java fundamentals and control flow
- `Functions` - methods and basic problem solving
- `Patterns` and `Patterns Part2` - console pattern exercises
- `Basic_Sorting_Algorithms` - bubble, selection, insertion, counting, and built-in sorting
- `Arrays part 1` and `Arrays Part II` - searching, subarrays, Kadane's algorithm, stock profit, and array problems
- `2D Arrays` - matrix traversal, diagonal sums, spiral matrices, and searching
- `ArrayList` - ArrayList operations, pair sum, and two-pointer problems
- `Strings` and `Regex_java` - string manipulation, palindrome checks, substrings, and regular expressions
- `Recursion` - recursion, tiling, Tower of Hanoi, duplicate removal, and related problems
- `BackTracking` - subsets, permutations, Sudoku, grid paths, and N-Queens
- `LinkedList` - linked-list implementation and operations
- `Divide_and_Conquer` - merge sort, quick sort, and rotated-array problems
- `Bit_Manipulation` - bitwise operators and bit manipulation exercises
- `OOP's_Java` - classes, constructors, inheritance, abstraction, interfaces, polymorphism, and static members
- `Packages` - Java package and access examples

## Suggested Learning Order

1. Java fundamentals: variables, operators, conditions, loops, and functions
2. Arrays, strings, ArrayList, and basic sorting
3. Recursion and divide-and-conquer algorithms
4. Linked lists, bit manipulation, and two-dimensional arrays
5. Backtracking and object-oriented programming

## Repository Structure

Each folder represents a topic, and each `.java` file is a focused exercise or implementation. The examples are intentionally small so that the logic can be read, compiled, modified, and tested independently.

## Contributing to Your Own Practice

When adding a new exercise:

1. Place it in the folder for its topic.
2. Use a descriptive class and file name.
3. Include a small `main` method when the program needs a runnable example.
4. Compile the file locally before committing it.
